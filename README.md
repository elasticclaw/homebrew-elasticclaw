# homebrew-elasticclaw

Homebrew tap for [ElasticClaw](https://github.com/elasticclaw/elasticclaw).

## Install

```bash
brew tap elasticclaw/elasticclaw
brew install elasticclaw
```

## Upgrade

```bash
brew upgrade elasticclaw
```

## Usage

```bash
elasticclaw login https://your-hub.example.com --token your-token
elasticclaw list
elasticclaw create --name my-claw --template my-template
elasticclaw chat my-claw
```
